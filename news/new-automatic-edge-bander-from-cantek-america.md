# New Automatic Edge Bander from Cantek America
> Cantek America will unveil the MX380PRO automatic edge bander at IWF 2026. The machine features pneumatic quick-setting for fast edge thickness changes, a quick-change glue pot system, and comprehensive working units inc
## Source summary

Cantek America will unveil the MX380PRO automatic edge bander at IWF 2026. The machine features pneumatic quick-setting for fast edge thickness changes, a quick-change glue pot system, and comprehensive working units including pre-milling, end trimming, top/bottom trimming, corner rounding, profile scraping, flat/glue scraping, release agent spray, and cleaning agent spray. It is designed to streamline production and enhance quality.
