## Source summary

Woodshop News reports on new woodworking tool innovations from multiple manufacturers. Whiteside introduces Brad Point Drill Bits for CNC machines, designed for drilling without burning. Fisch Tools offers Black Shark Forstner bits optimized for higher RPM. MicroJig launches Wave Reversible Glue Joint Bit with a decorative wave pattern and reduced material loss. Amana Tool adds ZrN-coated CNC tools with reduced shank design. Freud America introduces Quadra-Cut system with four cutting faces and Black I.C.E. coating. Vexor Custom Woodworking Tools introduces carbide-tipped groovers in hard-to-find widths. Infinity Tools offers Insert-Pro system with multiple knives per head. Charles G.G. Schmidt & Co. introduces multi-profile tools with corrugated backer plates. Leitz Tooling develops DFC Turbine for dust control. Vortex Tool Co. offers Laser Edge Diamond PCD insert tooling.

## Key facts

- Whiteside introduces Brad Point Drill Bits for CNC machines with diameters 5/32", 3/16", 5mm, 1/4" and max cut depth 1".
- Fisch Tools offers Black Shark Forstner bits optimized for higher RPM in softwoods and hardwoods.
- MicroJig launches Wave Reversible Glue Joint Bit with 2.5mm wave pattern and 5mm total material loss per joint.
- Amana Tool adds ZrN-coated CNC tools with gold zirconium nitride coating and reduced shank design.
- Freud America introduces Quadra-Cut system with four cutting faces and Black I.C.E. coating.
- Vexor Custom Woodworking Tools introduces carbide-tipped groovers in widths 1/2" to 1-1/4" and diameters 4", 6", 8".
- Leitz Tooling develops DFC Turbine that removes up to 90% of chips/dust and mounts on ThermoGrip chuck.
